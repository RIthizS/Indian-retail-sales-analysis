# 🛒 Indian Retail Sales Analysis

## 📊 Project Overview

This project analyzes Indian retail sales data to understand sales performance, customer behavior, product trends, and overall business performance.

The project was completed using **Excel, SQL, and Power BI**.

## 🎯 Project Objectives

The main objectives of this analysis are to:

- Analyze overall sales performance
- Identify top-performing products and categories
- Understand sales trends
- Analyze customer purchasing patterns
- Compare sales across different regions
- Identify important business insights
- Create an interactive Power BI dashboard

## 🛠️ Tools Used

- **Excel** – Data cleaning and initial analysis
- **SQL** – Data querying and business analysis
- **Power BI** – Data visualization and interactive dashboard

## 🔍 Analysis Performed

### Excel

- Data cleaning
- Data formatting
- Basic calculations
- Pivot tables
- Sales summaries

### SQL

- Data filtering and sorting
- Aggregations using `SUM`, `COUNT`, and `AVG`
- `GROUP BY`
- `ORDER BY`
- Conditional analysis
- Business-focused queries

### Power BI

Created an interactive dashboard to analyze:

- Total sales
- Sales trends
- Product/category performance
- Regional performance
- Customer-related metrics
- Key business KPIs

## 📈 Key Business Questions

This project focuses on questions such as:

1. What is the overall sales performance?
2. Which products generate the highest sales?
3. Which categories perform best?
4. Which regions generate the most revenue?
5. How do sales change over time?
6. Which products or categories need improvement?
7. What are the major trends in the retail business?
